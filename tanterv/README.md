# Godot Learning Notes

> Saját tanulási jegyzetek a Godot Engine és a GDScript programozási nyelv elsajátításához.

---

## A repository célja

Ez a repository a saját tanulási folyamatom során készült jegyzeteket tartalmazza.

A cél nem a hivatalos dokumentáció lemásolása volt, hanem egy olyan tananyag elkészítése, amelyet később én is könnyen vissza tudok olvasni, illetve más kezdők számára is hasznos lehet.

A legtöbb magyarázat saját szavakkal készült, ezért előfordulhat, hogy néhány fogalom egyszerűbben vagy "hétköznapibb" módon van megfogalmazva.

## Gyakorlati projekt

A repository egy egyszerű 2D platformer játék elkészítésén keresztül mutatja be a Godot alapvető működését.

A projekt során elkészül:

- Player
- Kamera
- Platformok
- Coin rendszer
- Enemy
- UI
- Audio
- Export
